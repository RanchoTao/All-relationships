# 词条编辑约定

Phase 1 不提供在线写入。所有增量内容在独立修订中编辑、校验、评审。

1. **保留原始证据。** 不修改 `data/raw/` 和已归档 v0.2 草稿来消除历史错误。建立新版本，保留来源定位、稳定 ID、修订理由和日期。
2. **先辨认概念。** 区分原型、变体、情境、结构属性、角色与状态；不要求互斥。名称近似不自动视为同义。
3. **定义有身份。** `source_fact` 仅说明指定来源支持的有限事实，`working_definition` 为编辑工作定义，`theoretical_inference` 记录推理链与条件，`unverified` 明确待核验。审核者核实依据与范围后才能改变 review。
4. **按主张引用。** 每个属性、关系边、生命周期变化引用 evidence ID；文献标题相近不能替代逐主张核验，概览 bibliography 不得自动批量挂到每个词条。
5. **保留不确定性。** “可能”“通常”“在特定法域”不能被去掉。缺失不同于“不涉及”，未验证不同于错误。不要替 456 条空定义自动填入百科口吻。
6. **不要让描述变成要求。** 通用协商提示与描述属性分别表达；不把常见互动变为默认责任。法律主张需要法域、日期和适用条件。
7. **风险条目只作描述。** 强制、欺凌、骚扰等不能成为关系建立模板；不对具体人物作未经证实的认定。
8. **合并需可追溯。** 保留所有旧 ID，通过显式别名或重定向关系说明，不物理删除原始记录。多人概念的成员集合与角色保持完整。

每次更新至少运行数据校验、搜索与缺失值语义测试、构建；影响呈现或交互时追加相应浏览器回归。当前 321 条原型归属缺口需要逐批核对，不能通过无依据的一对一重命名消除。
