# 关系倾向探索：研究设计（Phase 1 接口预留）

版本：2026-11-09。状态：研究提案，未实施招募，未收集个人数据，未生成正式题库或测评算法。

## 目的与解释边界

目标是帮助用户表达“我在目前情境下希望怎样与他人联结”，输出可查看、修改、否认的多维偏好画像。画像不等于固定关系类别、人格本质、精神健康诊断或择偶成功概率。Wiki 的词条不是心理测量题项，479 个名称也不是 479 个互斥标签。

6–12 道动态题仅是希望降低作答负担的产品假设。十个维度未必能在这一题量内得到足够信息；不得先锁定题数再宣称可靠。允许部分维度保持未知，并说明未被询问或信息不足的原因。

## 拟研究维度

| 维度 | 需要区分的内容 | 不允许的推断 |
| --- | --- | --- |
| 关系目的 | 陪伴、活动、生活协作、成长、照护、资源合作等，可并存 | 目的不同等于不适合建立关系 |
| 情感亲密 | 自我披露、支持、被理解的期待，区分频率与深度 | 低披露等于冷漠或依恋异常 |
| 浪漫需求 | 对浪漫表达、互动及称谓的当前偏好 | 推断性别、性倾向或永久身份 |
| 身体亲密边界 | 不同形式的接触、情境和可撤回同意 | 当前答案等于对任何人的授权 |
| 长期承诺 | 持续时间愿望、投入与不确定性容忍 | 承诺必然包含婚姻或排他性 |
| 排他性偏好 | 不同互动领域中的约定，知情协商前提 | 单一“忠诚度”或道德排序 |
| 独立空间 | 时间、居住、社交、隐私的自主需要 | 独立等于拒绝亲密 |
| 时间投入 | 可投入时间与希望投入时间，情境限制 | 忙碌等于不重视关系 |
| 物质和经济合作 | 费用、资源共享、独立性、责任边界 | 从收入、身份推断价值或信用 |
| 自愿协商规则 | 沟通、修订、信息披露与退出的偏好 | 把系统提示当强制协议或法律意见 |

维度结构本身也是研究假设。部分维度可能是多个不可加总的偏好，不能默认它们构成单一反映性潜变量，也不预设总分。

## 题目设计原则

1. 明确时间窗口和关系情境；同一人在友谊、共同生活、创业协作中的偏好可能不同。
2. 一题只问一个可理解的内容，避免“愿意亲密并且长期排他”等双重问题；不使用道德化或诱导措辞。
3. 提供“不确定”“不适用”“跳过”和中途结束。缺答不得自动计为中点、拒绝或低需求。
4. 分开询问“想要”“目前能够”“愿意协商”，不要混淆现实资源限制与意愿。
5. 敏感内容先说明用途与可跳过，不要求真实对象姓名、联系方式、位置、聊天记录或身份证明。
6. 结果回显题目依据，支持局部修改和“这不符合我”。修改后显示版本变化，允许全部否认；不将否认当作抵触或异常。
7. 多人关系用参与角色与整体安排表达，不强行改写成两人承诺；区分个人偏好和所有参与者实际同意。
8. 本阶段不提供正式题目清单、计分键或关系推荐权重。

## 动态选题研究路线

第一步研究可解释的分支流程：覆盖用户主动选择的维度，优先澄清歧义和未知，避免反复追问不愿回答的内容。这只能称为动态探索，不能因题目自适应就称为经过验证的 CAT。

如果将来确有数据支持潜变量及题项模型，再比较多维 IRT、贝叶斯偏好模型和透明规则分支。候选目标是减少画像不确定性，但必须同时限制敏感度、作答负担、维度覆盖和题目曝光。不得只优化把人分到某一关系类别的准确率。

选题过程应保留：当前已知与未知、为何选这道题、可替代题、版本和停止理由。用户随时可以停止，停止后仍可得到带未知项的自述摘要。精度停止阈值需要预注册、校准和验证；6–12 题不能成为效度声明。

研究中至少比较固定短版、透明分支版、自适应候选版和用户直接自述。分别报告作答负担、维度覆盖、误解、用户修正率、不确定性校准和重复结果稳定性。模拟表现不能代替真人验证。

## 验证计划与进入下一阶段的条件

| 阶段 | 方法 | 要保留的证据 / 停止条件 |
| --- | --- | --- |
| 构念与内容审查 | 目标使用者和相关研究者分别审阅维度范围、措辞、遗漏 | 保存分歧；内容不清晰时不开始计分校准 |
| 题项理解测试 | 小批次、多轮认知访谈；复述题意、解释选项与回忆过程 | 区分字面理解、情境选择和作答顾虑；修订后重新访谈 |
| 可用性与接受度 | 自愿小规模原型研究；记录跳过、修改、拒绝结果的原因 | 不把高完成率当效度；出现压力或误解则修改流程 |
| 重测稳定性 | 预先说明时间窗口，暂拟 1–2 周重测并记录真实情境变化 | 区分测量误差与真实偏好变化；报告置信区间和样本流失，不仅相关系数 |
| 结构及效度研究 | 依据构念性质选择结构检验；预注册收敛、区分和解释性假设 | 无“真实关系类型”金标准；不把用户认可或 Wiki 标签一致率当唯一效度 |
| 自适应校准 | 在足够样本和题项覆盖后比较选题策略、局部依赖与参数稳定性 | 样本量由模拟、精度目标和设计决定，当前不伪造固定足够人数 |
| 外部验证 | 独立样本、不同语言与生活情境；检查差异题项功能及缺答偏差 | 不默认跨文化可比；无法支持的群体、维度或用途明确限制 |

仅当内容可理解、构念适切、误差和局限可解释、隐私与自愿机制有效且独立验证支持预定用途时，才考虑标示特定用途的验证结果。任何阶段均可缩小范围或停止版本，不将整个方向的研究失败归结为用户“不配合”。

## 接口与隐私

`src/lib/assessment-contract.ts` 仅定义维度、带缺答状态的回答、画像及未来研究适配器。没有实现 `proposeNext`、`summarize`，没有题库、测评页面、上传接口、Cookie 或分析追踪。

下一阶段需要单独授权招募和数据收集方案。优先本地临时计算和用户自行导出；服务器存储不是默认要求。若研究确需留存，预先明确目的、最少字段、撤回和删除方式、保留期、访问控制和适用伦理审查。不得把结果自动传入 Dearwithme 或用于真实匹配。
