## 测评交付

入口 `/explore`，题库与规则 `/explore/method`。14 题题库按需求分为 6–12 题路径，34 个可审查阅读模板。先检查已答必要条件，再按明确偏好排序；未知必要属性不能通过。输出最多 5 项，数量不足不凑数。

报告包含主要需求、多维自述、支持理由和逐项规则、冲突安排、未知事项、后续问题及 Wiki 链接。可以改答、继续未完成问题、自由补充、否认候选／整轮结果、清空重来。自由文本不被解释或自动评分。

成年人敏感题需先确认成年且可跳过。没有默认答案上传或持久存储，没有答案 URL、数据库或分析埋点。自愿分享只复制固定通用介绍。规则与隐私说明见 [测评文档](PHASE2_ASSESSMENT.md)，[题库草案](PHASE2_QUESTION_BANK.md) 可离线审阅。

## 最终本地验证结果

环境：Windows，Node 25.2.1；Next.js 16.4.1 静态导出；Playwright 使用本机 Edge 独立无头会话。未新增依赖。

- `npm run validate:data`：通过，历史层及新层校验均通过。
- `npm run test:unit`：20 项通过。覆盖四类虚构需求、分支终止、硬条件失败与未知、年龄门槛、矛盾保留、分支清理、改答排序、否认、无效输入、内容字段、来源／链接和分类筛选一致性。
- `npm run typecheck`、`npm run lint`：通过。
- `npm run build:pages`：通过，487 个静态页面生成，479 个原 ID 详情路径完整。
- `npm run test:pages`：**31 项通过，2 项有意跳过**。跳过的是平板／手机重复的全量路由枚举，该枚举在桌面项目中已检查所有 479 条；不是跳过功能失败。
- 三视口：1440×1000、820×1180、390×844。每个视口都完成长期伴侣、友谊、活动、科研的实际问卷闭环，并验证改答、未知、否认、年龄、清空与阅读链接。
- axe WCAG 2 A／AA、2.1 AA 自动规则：旧六个页面及新增问卷、报告、深度卡检查中未检出违规。修复过报告定义列表的按钮层级问题；不是 WCAG 全面认证。
- 浏览器检查未发现页面脚本错误、横向溢出、问卷写请求、第三方请求或答案本地持久存储。刷新清除问卷状态。
- 复核真实渲染截图，保留原品牌、中文排版、色彩与响应式；没有声明“已经达到获奖级”。

## 准确性仍不能保证的部分

**功能验收通过不等于测评科学有效。** 无真实用户验证、代表性样本、信效度校准、推荐准确率或关系结果研究。题目与权重是可审查的编辑规则；模板对人际关系的覆盖仍有限，不能判断某个真实对象是否满足双向需求。

内容没有独立人工／领域专家逐条审核；31 张新卡尚无外部背景来源，419 项尚未完成标准内容。分类粒度、近义词和跨文化表述需要持续修订。共同育儿来源全文本轮不可读取，不能把摘要线索扩展成已证明结论。

本次是 Edge 桌面与模拟视口测试，不是 iOS／Android 真机、Safari、屏幕阅读器或真人可用性认证。没有宣称进行了专业法律审核或完整安全审计。

## 仓库与发布边界

开发分支 `feat/phase2-knowledge-explorer`。PR 只运行已有 Pages 验证流程，不触发部署；GitHub Pages 的静态导出、子路径和 main 发布结构保留。本轮不自动合并或改动正式网站配置。远程检查状态以 PR 的实际 CI 记录为准，本报告记录上述本地复核。

本地体验：`npm run preview:pages`，访问 `http://127.0.0.1:3101/All-relationships/explore/`。完整初始化与重现步骤见仓库 README。
