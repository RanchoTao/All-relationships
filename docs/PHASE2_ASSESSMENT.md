# 关系偏好探索 v0.1：题库、规则、隐私与效度边界

## 定位

这是当前自述需要的整理与百科阅读导航，不是人格分类、诊断、真实对象匹配或关系结果预测。不推断精神健康、性倾向、人格缺陷或违法行为。不依赖收费模型或外部 API。

可审查题库和模板的完整可读版本位于网站 `/explore/method`；代码单一来源为 `src/lib/assessment.ts`。题库 14 题，34 个阅读模板。实际路径 6–12 题：

| 目的             | 额外分支                         | 总题数 |
| ---------------- | -------------------------------- | ------ |
| 友谊／目的未知   | 共同核心六题                     | 6      |
| 活动             | 活动场景                         | 7      |
| 科研             | 协作角色、资源                   | 8      |
| 学习／社区       | 资源                             | 7      |
| 居住             | 资源、住所                       | 8      |
| 恋爱，未确认成年 | 年龄门槛，不显示成年人细分题     | 7      |
| 恋爱，确认成年   | 年龄、浪漫、身体边界、排他、住所 | 12     |

共同核心六题是目的、情感陪伴、期限、时间、独立空间和沟通规则。每题都有选项依据说明，均可不确定、跳过、不适用。任何时刻可以看信息不足的部分报告；先问目的，再分支，顺序固定，不使用随机或模型自适应。不会声称六题具有充分信息量。

## 确定性规则

1. 清洗输入，未知选项不成为答案；未回答、跳过、不确定、不适用保持各自状态。
2. 根据主要目的确定候选池。成年人模板需明确成年声明；未声明不按成年处理，隐私题不会显示。成年声明不是身份核验。
3. 用户标为必要条件的已答项逐条检查。模板明确不支持则排除；模板该属性缺失则待确认，不能算已满足。
4. 必要条件检查后才排序：目的匹配固定 6 分，每个已知支持项加 2，每个非必要条件差异减 1，未知 0；同分按稳定 ID。界面不用分数冒充适配率。
5. 取最多 5 项；不足 3 项不补假结果。信息不足时可以没有建议。每项显示答案 ID、模板属性、判定及编辑依据；必要条件未知单列。
6. 若恋爱目的与明确不希望浪漫相冲突，保留两项回答，暂停推荐并请求澄清，不替用户决定真需求。
7. 修改目的／年龄后清除不再适用分支答案；改答重新计算。否认某项使其退出本轮列表；否认全报告隐藏建议。自由补充只由用户阅读，不进入文本推断或自动评分。

模板值是为阅读探索定义的**可协商安排**，不是对全部该类关系的经验测量。例如，某模板允许每周安排，并不证明所有朋友都每周见面。无性浪漫、分别居住等额外议题没有被测全，范围说明会提醒仍需确认；未询问婚姻目标，不可把候选阅读入口说成用户已经选择不婚。

## 隐私

答案仅在 React 页面状态中存在。不写 localStorage、sessionStorage、cookie、URL、日志或后端。刷新／清空会丢失，不做跨页面保存。没有数据库、账户、统计埋点、第三方字体或模型请求。静态网站托管方仍可能保留普通访问日志；用户主动访问某个百科路径本身也会产生网页请求，不等于完全匿名网络访问。

分享为用户点击后的通用文本复制，固定不含答案、候选 ID、关系方向、备注和分数。没有自动分享、含私密信息的网址或社交发布。外部来源链接使用新标签和 noreferrer。

## 测试和科学有效性

单元测试覆盖不同目的、分支长度、必要条件失败、未知必要属性、状态区分、年龄变更、矛盾、拒绝、无效输入和路径终止。浏览器使用虚构输入，验证从头至尾、修改与清空、三视口、axe、无写请求／外部请求、无存储和刷新清空。

这些只证明有限场景下程序符合声明的规则。**没有**代表性样本、量表信度、结构效度、重测稳定性、跨文化验证、推荐准确率、关系满意度或结果改善的研究证据。不存在“准确率 98%”或“真实人格类型”。

下一阶段建议先开展 8–12 名自愿成年参与者的认知访谈：逐题复述理解、识别歧义、记录不适与遗漏；再用明确同意和数据最小化方案测试阅读结果是否有用。该人数是可用性试验设计提议，不足以证明量表效度。开展真实研究前先确认招募、同意、保存期限和退出删除流程，本轮没有收集这些资料。
