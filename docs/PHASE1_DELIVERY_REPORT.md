## 技术与开源组件

Next.js 16.4.1 App Router、React 19.3.1、TypeScript 6.0.3、Tailwind CSS 4.3.5、Zod 4.6.7、Fuse.js 7.5.0、React Flow 12.12.1、Lucide React 1.70.0。检验使用 Node test runner、Playwright、axe-core、ESLint 和 Prettier。具体可复现版本见 `package-lock.json`。

所有内容从本地 JSON 加载；搜索在浏览器执行；图谱动态加载并限制每组最多 12 个词条，不运行全局力导向模拟；详情预生成。源数据与规范性规则分离，证据、可选知识字段、多角色超边与时间叠加接口见 [`DATA_MODEL.md`](DATA_MODEL.md)。

ESLint 使用与 Next 配套插件声明兼容的 9.x；安装器提示该开发工具版本已结束支持。后续应随插件兼容更新一并升级，不通过忽略 peer dependency 冲突安装 10.x。这个限制不影响已运行的构建、类型检查和浏览器测试。

## 实际 UI 复核

除自动测试外，使用应用内浏览器检查了桌面、平板和手机呈现，以及手机锚点导航、FWB 搜索和卡片显示；并人工查看自动化截图中的卡片、详情、比较和图谱。

已修复：桌面引导区过高导致卡片出现太晚；卡片辅助文字和详情侧栏的对比度不足；筛选控件缺少稳定的显式无障碍名称；移动端介绍卡的孤字换行；搜索框重复的清除图标。保留低干扰悬浮反馈与减少动态效果支持。

手机比较表格具有独立横向滚动区，整页不横向滚动。图谱的小屏全景用于定位，文字可通过缩放、居中或文本目录阅读。大量词条通过渐进加载及图谱分页控制开销。

截图保存在 `artifacts/screenshots/`，可运行测试重新生成。交付快照：[桌面](ui/desktop-home.png)、[平板](ui/tablet-home.png)、[手机](ui/mobile-home.png)。自动扫描通过不代表所有辅助技术、所有屏幕及所有真实设备都经过验证，也不代表视觉奖项认证。
